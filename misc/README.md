# References

`references/` is intentionally gitignored and is local study material only.
Recreate it with `./misc/fetch-references.sh`.

- [GitNexus](https://github.com/abhigyanpatwari/GitNexus) is studied for its
  behavior, product surface, architecture, tests, parsing and resolution
  choices, pain points, and user experience. Its license is not permissive for
  BlastRay's intended reuse: do not copy, translate, port, adapt, or derive
  implementation code from it.
- [Kodegraf](https://github.com/DeRaowl/Kodegraf) is MIT licensed and is studied
  for its Rust implementation, including Tree-sitter, indexing, symbols,
  relationships, incremental updates, storage, MCP transport, and language
  support. No code is copied during Mission 0. Any later reuse must preserve
  applicable MIT attribution and license obligations.
- [Stockfish](https://github.com/official-stockfish/Stockfish) is studied only
  as a codebase-quality reference: compact structure, direct naming,
  performance, restraint, and build/test discipline. It is GPL licensed; do
  not copy implementation code from it.
